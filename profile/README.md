# שבח בע"מ

## כלל: ריפו חדש נפתח רק כאן

כל ריפו חדש של העסקים נפתח **בארגון הזה**, ולא בחשבון גיטהאב אישי.

- רק מנהלי הארגון יכולים לפתוח כאן ריפו. צריכים ריפו חדש? פונים לשילה והוא פותח אותו.
- יש ריפו של העסקים בחשבון אישי? פונים לשילה והוא מעביר אותו לכאן.

כך כל הקוד של העסקים נמצא במקום אחד, וכל מי שצריך גישה מקבל אותה.
